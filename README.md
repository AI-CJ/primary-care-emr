# Primary Care EMR

## Goal
The goal of this project is to design and build a modern, user-friendly primary care electronic medical record system from the ground up. It will include tools for clinical staff to manage patient care and a separate patient portal where patients can view and manage their health information. The project is also intended to help me learn the full process by planning, building, testing, and improving the system myself as it grows.
## Current Scope
Stage 0 - Building basic foundation for a primary care EMR using synthetic patient data. The first usable workflow will let staff find a patient and open a simple patient chart. 
## Data Rule
This project will use synthetic patient data only. No real patient names, dates of birth, contact information, medical records, insurance information, lab results, billing information, or other protected health information will be stored in the application, source code, GitHub repository, screenshots, logs, or test data. Any patient information used for development and testing must be fictional but may be designed to look realistic enough to test real-world workflows.
